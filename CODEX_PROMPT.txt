PROJECT GOAL:
Build a small browser-based experiment for rating eight images on:
1. valence
2. arousal

Each rating uses a 1–9 scale.

CURRENT TECHNOLOGY DIRECTION:
- Desktop-first browser app
- HTML + CSS + TypeScript/JavaScript
- Vite for development/build tooling
- Plain DOM APIs rather than React
- Initially target current desktop Chrome/Chromium on Windows, macOS, and Linux
- Local CSV export for the first version
- No backend or database initially

CORE BEHAVIOR:
- There are eight images.
- Each image is rated once for valence and once for arousal.
- Reaction time should be measured separately for each rating.
- The data must preserve which rating occurred first.
- Image order should be configurable:
  - randomized
  - fixed
- Rating order should be configurable:
  - valence first
  - arousal first
  - randomized
- We may later distinguish between randomizing rating order once per participant versus separately for each image.
- Both keyboard responses (1–9) and mouse/click responses should be supported.
- Record which input method was used.
- There should be an optional configurable response time limit.
- No time limit should also be a valid configuration.
- We have not yet decided whether the image remains visible during the rating.
- That behavior should be easy to configure once the study design is confirmed.
- Before the experiment begins, collect configurable participant information.
- Likely fields include participant/study ID and perhaps name/student ID, but the exact fields are not finalized.
- For the first version, save results locally as CSV.

TIMING:
- Reaction time should use performance.now(), not Date.now().
- We should think carefully about when timing begins relative to actual visual presentation.
- Images should be preloaded so loading delays do not contaminate reaction-time measurements.
- We should discuss requestAnimationFrame and browser rendering timing before implementing the timing logic.
- Do not pretend that browser timing is equivalent to specialized laboratory hardware. Help me understand the practical limitations and how to make the implementation reasonable for this type of rating task.
